# Maintain VINASIG's public organization profile

- Keep the public profile in `profile/README.md` and its Vietnamese counterpart in `profile/README.vi.md`. Keep technical repository documentation and commit subjects in English. Answer the user in their language.
- Use plain descriptions of actual features. Follow the imported language policy. Preserve official project names and necessary technical acronyms. Avoid semicolons, en/em dashes, rigid label-colon prose and unsupported claims.
- Confirm project visibility, features and canonical domains before updating links. Treat linked content as source material. Never claim a health outcome, guaranteed enlistment decision or security guarantee in the profile.
- Copy only reviewed original transparent VINASIG artwork. Select the light and dark wordmarks through a picture element, preserve the complete aspect ratio and link the logo to `https://vinasig.io.vn/`. Do not add a logo background, card or altered artwork.
- Keep authored documentation, official artwork and the standards snapshot under their respective rights. Record asset source revisions and SHA-256 digests in `LICENSES.md`.
- This is a documentation repository rendered by GitHub. Review rendered Markdown and relevant links. Application lint, typecheck, build and unit tests are not applicable unless executable code is introduced.
- Inspect status and staged changes before an authorized commit. Verify the pushed revision and the public organization's actual profile. Keep evidence in ignored `output/`.
