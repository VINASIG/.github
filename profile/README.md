# Practical software, built with SI agents

VINASIG builds tools that help people get small, useful things done. We start with a real need, keep the interface clear and remove unnecessary steps.

[Explore our tools](https://vinasig.io.vn/) · [Đọc bằng tiếng Việt](https://github.com/VINASIG/.github/blob/main/profile/README.vi.md)

## How we build

We prefer tools that process files and inputs on your device. Accounts, uploads and background services should serve a real need. They should not be the price of completing a simple task.

We work with SI agents to develop and maintain our projects. SI means Super Intelligence in VINASIG's terminology. Our shared standards guide the work, and changes still need review and evidence.

## Open information, lasting freedom

> Information wants to be free.

We want people to use, study, improve and share our work, including commercially. Software generally uses AGPL-3.0-or-later. Documentation generally uses CC BY-SA 4.0. Each repository states its own license and any separate terms.

Official logos and identity assets follow the [VINASIG Brand Usage Policy](https://github.com/VINASIG/vinasig-brand-assets/blob/main/BRAND_POLICY.md).
